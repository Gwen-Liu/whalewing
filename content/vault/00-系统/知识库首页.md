# 知识库首页

这一页告诉你和接入的 AI：要找什么，去哪里找。导航只负责指路，具体结论要回到原文看。

## 第一次接入，先读这三篇

1. [关于我](../30-领域/个人管理/关于我.md)：员工是谁、想去哪里、怎样协作。
2. 本页：东西放在哪。
3. [知识库规则](规则/知识库规则.md)：分类、属性、怎么写，每日记忆和每周思考怎么做。

## 快速查找

| 要找什么 | 去哪里 |
| --- | --- |
| 关于我、发展目标与待办、重要决定 | `30-领域/个人管理/` |
| 本周要我拍板的事、本周思考 | 最新一篇周记 `60-时间线/周记/YYYY/YYYY-Www.md` 的开头 |
| 某一天做了什么 | `60-时间线/日记/YYYY/YYYY-MM-DD.md` |
| 某件事的来龙去脉 | `60-时间线/任务/YYYY-MM/`；早先的在 `00-系统/索引/任务`；`00-系统/Bases/任务记录` 视图两处都列 |
| 日常怎么用 | [知识库使用说明](规则/知识库使用说明.md) |
| 文章、报告和讲解稿的写法 | [作品写作规范](规则/作品写作规范.md) |
| 新建笔记的骨架 | [正式笔记模板](模板/正式笔记模板.md)列出各类型模板 |
| 还没决定的事 | `10-收件箱` |
| 有目标、会结束的事 | `20-项目`（工作、学习） |
| 一直要维护的方面 | `30-领域` |
| 学到的认识和主题地图 | `40-知识` |
| 书、网页、课程、会议的出处 | `50-来源` |
| 自己做出来的东西 | `70-作品`（报告、文章、PPT） |
| 库外的文件和系统在哪 | `80-外部索引` |
| 结束了的内容 | `90-归档` |

库从空内容开始，不预装别人的知识；目录在不代表已经有内容。新增重要入口、目录用途变了时再更新本页，日常新增同类笔记不用登记到这里。
