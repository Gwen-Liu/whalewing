# 任务记录模板

一件值得记的事一篇：一次排查、一个功能做完、一次重要讨论。放在 `60-时间线/任务/YYYY-MM/`，文件名和 H1 写“日期 + 做了什么，结果如何”，日期取事情发生的那天。写法见[知识库规则](../规则/知识库规则.md)的“任务记录”一节。

`status`：`done` 做完了，`open` 还在进行，`paused` 搁置。同一件事后来有了进展，改这一篇，不另开一篇；用不上的小节删掉。

```markdown
---
type: timeline
timeline_type: task
date: YYYY-MM-DD
status: done
project:
created: YYYY-MM-DD
updated: YYYY-MM-DD
aliases: []
---

# YYYY-MM-DD 做了什么，结果如何

两三句话：什么事、结果、现在怎样。

## 经过

## 我纠正了什么

## 下次遇到同类事

## 还没验证的

## 相关
```
