# 正式笔记模板

新建前先找一找有没有现成的主文件，按[知识库规则](../规则/知识库规则.md)选类型、状态、目录和名字。模板只是骨架，不代表已经有内容。各类型有专用骨架时优先用：

| 对象 | 模板 |
| --- | --- |
| 项目 | [项目模板](项目模板.md) |
| 领域 | [领域模板](领域模板.md) |
| 原子笔记 | [原子笔记模板](原子笔记模板.md) |
| 主题导航 | [MOC模板](MOC模板.md) |
| 书籍来源 | [书籍来源模板](书籍来源模板.md) |
| 网页剪藏 | [网页剪藏模板](网页剪藏模板.md) |
| 作品 | [作品模板](作品模板.md) |
| 外部索引 | [外部文件索引模板](外部文件索引模板.md) |
| 日记、周记、月记 | [日记模板](日记模板.md)、[周回顾模板](周回顾模板.md)、[月回顾模板](月回顾模板.md) |
| 任务记录 | [任务记录模板](任务记录模板.md) |
| 待定事项 | [待定模板](待定模板.md) |

没有专用模板的对象（如课程、会议来源、人生事件）用下面的通用属性：

```yaml
---
type: atomic
status: seedling
created: YYYY-MM-DD
updated: YYYY-MM-DD
aliases: []
---
```

正文写清一条认识：是什么、为什么、举一两个例子、什么时候不适用，以及相关笔记的链接。来源、项目这类属性有对应的笔记时才加。

项目页写目标、范围、现在怎样、风险和下一步；来源笔记写出处、日期、在哪一页或哪一分钟、自己的理解；外部索引写原件在哪、做什么用、注意什么。没有的字段不留空壳，没确认的事不写成定论。
