# 视觉物料

## 先定用途和画幅

先确认：用在哪（公众号、小红书、视频平台、PPT、打印）、给谁看、要传达的一句话、交付几张、有没有品牌色和字体、有没有参考图。平台尺寸会调整，以员工给的或平台当前说明为准；常用的有：

| 用途 | 比例 | 常见尺寸 |
| --- | --- | --- |
| 公众号首条封面 | 2.35:1 | 900×383 |
| 公众号次条封面 | 1:1 | 500×500 起 |
| 小红书图文 | 3:4 竖版 | 1080×1440 |
| 横版视频封面、PPT | 16:9 | 1920×1080 |
| 竖版视频封面 | 9:16 | 1080×1920 |
| 打印海报 | A4／A3 竖版 | 300 dpi，四边各留 3 mm 出血 |

标题和关键文字放在安全区里，避开平台会裁切或叠加按钮的边缘。

## 拆内容

- **原文为准**：标题用员工或原文给的，不自己编；数据、名称、引语照原文写，不改写、不凑数。原文里的密码、密钥、内部链接等敏感内容不进图。
- **封面**：只放标题，最多加一句副标题；一个视觉焦点。
- **信息图**：先写出读者看完要记住的两三点，再按内容关系选版式：先后顺序用流程或时间线，两方对比用左右对照，多项多维用对比矩阵，层级用金字塔或树，围绕一个中心用中心放射，转化或筛选用漏斗，指标用看板，多个并列主题用宫格。信息层级不超过三层。
- **图文卡片系列**：先定一条线，再拆成 1 到 10 张：第一张是封面，一张一个要点，最后一张收尾（总结或引导关注、收藏）。按内容选一种拆法：经历分享按“问题 → 发现 → 体验 → 结论”；教程、清单、对比按“核心结论 → 要点卡 → 优缺点 → 建议”；重画面的按“主图 → 细节 → 场景 → 收尾”。每张的文字量事先定：少（一两点）、中（三四点）、多（五到八点的干货卡）。
- **文章配图**：通读全文，只在读者需要“看一眼才明白”的地方配图：流程、对比、框架、时间线、数据，以及需要营造氛围的开头或转折。每处写清配图要说明什么，列出位置清单请员工确认，不每段都配。

## 定风格

用五个维度描述，新做时请员工确认（员工说“直接出”就按推荐做，并在出图前说明用了哪些设定）：

1. **类型**：大图冲击、概念抽象、以字为主、视觉隐喻、场景氛围、极简留白。
2. **配色**：主色、辅色、强调色写出色值；有品牌色先用品牌色。
3. **画法**：扁平矢量、手绘、水彩、像素、粉笔、版画、写实等，一套物料只用一种。
4. **文字量**：无字、只有标题、标题加副标题、带标签的多文字。
5. **情绪**：克制、平衡、强烈（对比度和饱和度随之变化）。

系列图（卡片、配图）全套用同一组设定，必要时用第一张作参考图保持一致。人物用简化形象，不画可辨认的真人；不模仿在世艺术家的个人画风，不使用来历不明的图片和字体。

## 选做法

- **员工接入了生图工具**（宿主或 MCP 提供的）：适合场景、插画、质感强的画面。每张图的完整提示词先存成文件（如 `prompts/01-cover.md`），再调用工具，方便换工具或改图时重来。中文字多、数字多、要求精确的，尽量让生图只出无字底图，文字用下面的 HTML 方式排在上面。
- **没有生图工具，或文字、数据要求精确**：用 HTML／CSS 或 SVG 排版（信息图、数据卡、以字为主的封面、图示都适合），在浏览器里按目标尺寸打开，截图或导出成 PNG；中文用系统自带字体或随文件附带的字体，不依赖外网字体。
- 两种都做不了时说清楚缺什么，问员工接入哪种生图工具或改用哪种做法，不假装出了图，也不用文字描述冒充图片。

生成的图里文字错了、糊了，不在原图上涂改遮盖；重新生成，或改出无字版再排字。改图前保留上一版，便于对比。

## 检查

- 实际打开每张图看过：缩小到手机信息流里的大小，标题还能看清。
- 文字没有错别字、乱码、截断，没有元素出界或互相压住，四周留有边距。
- 文字和背景对比清楚；一套图的配色、字体、画法一致。
- 内容和原文一致，没有编造的数据和引语。

## 交付与退出

交付：图片文件（写明尺寸和用途）、提示词文件或源 HTML／SVG（能再改）、用了哪些设定、哪些没做或没看过。员工要改就在原设定上改，交付完即退出；需要做成网页或交互原型时转用界面设计。
