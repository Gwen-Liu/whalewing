# 用好搜索工具

## 选哪个

- **百炼联网搜索**：国内的新闻、政策、公司和产品，中文网页为主。
- **Tavily**：英文和海外的资料、技术文档、论文；还能把一个网页的正文抽出来读。
- 两个都连上时，中文问题先用百炼，查不到或要海外视角再用 Tavily；只连上一个就用那一个。都没连上时直接告诉员工，不靠记忆编来源。

## 怎么搜

1. 关键词写具体：带上对象、时间和地区，比如“2026 年 新能源汽车 购置税 政策”，不只写“新能源政策”。
2. 搜索结果的摘要只是线索：要引用的结论，打开原网页读正文再用。
3. 同一个事实最好有两个互不相关的来源；只有一个来源、或来源之间说法不一的，写明。
4. 注意日期：政策、价格、版本号这类会变的，写清是哪天的说法。

## 交回

每条结论后面跟出处（网站名和链接），文末列出查过的来源。搜不到或打不开的，写“没查到”，不补。员工要存进第二大脑时，出处按知识库规则记进 `50-来源`。
