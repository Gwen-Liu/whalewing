# 功能测试

在真实浏览器里点鲸翼界面，按业务流程检查界面上看到的结果。和 `tests/` 里的单元测试分工：

| | 单元测试 `tests/` | 功能测试 `e2e/` |
|---|---|---|
| 测什么 | 规则、数据处理、组件逻辑 | 员工真正看到和点到的界面、整条业务流程 |
| 怎么跑 | 不开浏览器，几秒跑完 | 每个测试文件起一套临时 DSH，用无头 Chromium 去点 |
| 命令 | `npm test` | `npm run test:e2e` |

用例清单（正案例、反案例、出处、层级）见 [cases.md](cases.md)。用例由鲸翼内置的“测试专家”按需求文档生成，再对照实际界面审查定稿；每个测试上面一行注释写需求出处。

## 运行

```bash
npm run build
npm run test:e2e
```

只跑一个文件：`npm run test:e2e -- e2e/specs/model-world.test.mjs`；只跑名字里带某段文字的：再加 `--test-name-pattern="对决"`。走 `npm run test:e2e` 会用低优先级、限制并行数，卡住的测试到点会被结束，见[修改与验证](../MAINTAINING.md#修改与验证)。8 核以上两个文件并行，全部跑完约 4.5 分钟。

需要：

- **DSH**：默认用插件开发依赖里的 `@deepseek-ai/dsh`；也可以用 `WHALEWING_E2E_DSH_BIN` 指定 `lib/bin.js` 的路径。
- **Playwright**（Node 库和它的 Chromium）：默认在插件依赖里找 `playwright`；也可以用 `WHALEWING_PLAYWRIGHT` 指定包目录。找不到时直接报错，不会跳过。无头 Chromium 默认藏起滚动条，这里去掉了这个参数，滚动条和桌面版一样占位、能拖。

可选环境变量：

- `WHALEWING_E2E_OUT`：失败截图和证据放哪，默认系统临时目录下的 `whalewing-e2e-evidence`。
- `WHALEWING_E2E_KEEP`：设了以后，DSH 启动失败时保留临时目录，方便看日志。

## 结果怎么看

- `✔` 通过；`✖` 失败，下面有失败截图的路径。
- `⚠ … # 已知问题：…` 是和需求不符、已经确认的产品问题：断言按需求原文写，产品修好后去掉 `todo` 就成为普通测试。它不算通过。
- 需求里没写清的预期（清单里的“预期未定义”）不写成测试，等需求定了再补。

## 每次跑都从零开始

- 每个测试文件新建一个临时目录，里面是独立的 DSH_HOME、知识库和文档目录，只加载 DSH 原版基础包和本插件；不碰员工的正式 DSH 和 `~/.dsh`。
- 去掉本机所有 Key、Token、密钥类环境变量（例如 `WHALEWING_AA_API_KEY`、`DEEPSEEK_API_KEY`），关掉统计上报和会调用模型的自动起标题；不登录模型，DSH 弹出的“开始使用”自动关掉。
- 浏览器里发往本机以外的请求一律拦下并记在 `external` 里，功能测试不联网、不调模型；需要网页时在测试里用 `node:http` 起 127.0.0.1 的小页面。
- 测试要的数据在启动前放进临时目录，预期按这份数据算。例如模型世界用插件自己的数据整理代码把一份合成目录写进去（`support/world-fixture.mjs`），和员工点“更新数据”走同一条路。
- 每条用例用新的浏览器上下文；测完关掉 DSH，删掉临时目录（遇到联接只删链接本身）。
- 同一个文件里的用例共用一套 DSH：改了状态的用例（开关、Key、新建的数据）自己在 `finally` 里还原。

## 桌面版标题栏

DSH 桌面版在 Windows 上，窗口最上面 40px 是拖动窗口的区域，右上角约 138px 是窗口自己的最小化、最大化、关闭。浏览器版没有这两样，所以：

- `openWhaleWing(page, url, { desktop: true })` 给页面打上桌面版的标记，DSH 和鲸翼按桌面版排版；
- `titlebarProblems(按钮)` 按样式判断哪些按钮会被窗口按钮挡住、哪些压在拖动区域上点不中。`model-world.test.mjs` 里有一条自检：把查看器改回修复前的样子，检查必须报出问题。

真实的拖动和窗口按钮只有桌面版有，这类改动最后仍要在桌面版里点一下确认。

## 写测试时的几个坑

- 切过的页签留在页面里隐藏着，找页标题要加 `:visible`。
- `filter({ has })` 里的内层定位要从 `page` 写起，从外层元素写起一个都匹配不到。
- 弹窗和抽屉右上角“×”的无障碍名称和标题相同，点底部按钮用 `dialogButton(弹窗, '确认')`；“取消”和“取消计划”同在时加 `{ exact: true }`。
- 抽屉、弹窗是模态的，开着时右上角提示看得见但点不到。
- 个人知识的库要等插件第一次打开时自己建（目录非空会拒绝建库），测试笔记在建库后写进去。
- 临时 DSH 会建好每天北京时间 08:00 的每日资讯任务，避开在 08:00 前后跑。

## 目录

- `specs/*.test.mjs`：按页签分的用例，一个文件一套 DSH：`workbench`（页头、功能开关、按需加载）、`titlebar`（桌面版标题栏：各种弹层在小窗大窗都让出窗口顶部）、`experts`、`assistant`、`ai-web`、`knowledge`、`skills`、`schedules`、`toolbox`、`cards`、`model-world`。
- `support/dsh.mjs`：临时 DSH 的启动和清理。
- `support/browser.mjs`：找 Playwright、开页面、进鲸翼、切页签、提示和弹窗定位、桌面版标题栏检查、失败截图。
- `support/*-fixture.mjs`：各功能的测试数据和回读磁盘的函数。
