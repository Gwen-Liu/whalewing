# 鲸翼 WhaleWing

> 鲸翼 · DSH 超级个体工作台 —— 积厚培风，扶摇九万里

鲸翼是 DeepSeek Harness（DSH）的开源插件，在 DSH 里加一个个人工作台：事情交给小鲸和专家去做，做过的事沉淀进自己的知识库，常用的办公处理在这台电脑上完成。模型用你在 DSH 里配好的；知识、技能和配置都存在本机，不上传。

名字取自《庄子·逍遥游》：“北冥有鱼，其名为鲲……化而为鸟，其名为鹏。”DSH 是那条鲸，鲸翼给它装上鹏的翅膀。知识沉淀、技能复用、专家团队都是托起翅膀的风：“风之积也不厚，则其负大翼也无力。”标志“鲸尾为翼”的说明见 [art/brand](art/brand/README.md)。

## 功能

| 功能 | 做什么 | 类别 |
|---|---|---|
| [专家团队](#专家团队和小鲸助手) | 10 位内置专家各管一摊，每位有自己的记忆；可以用模板或自己新建 | 基础 |
| [小鲸助手](#专家团队和小鲸助手) | 总管：把事派给合适的专家、跟到做完、向你汇报 | 基础 |
| [知识积累](#知识积累) | 你自己的第二大脑：本机 Markdown 知识库、关系图谱、每日记忆和每周思考 | 基础 |
| [技能中心](#技能中心) | 管专家能用的技能、MCP 和插件包，随包带 94 项技能 | 基础 |
| [定时任务](#定时任务) | 到点自动做的事，可以交给某位专家 | 基础 |
| [AI 网页](#ai-网页) | 按要做的事找 AI 网站，一个问题带着背景发给几家，回答存回知识库 | 可选 |
| [办公工坊](#办公工坊) | 文件交给小鲸，在本机处理，44 项功能项 | 可选 |
| [每日阅读](#每日阅读) | 每天一期：今日资讯、今日一招、接着读和回顾；能存进收件箱、能划线 | 可选 |
| [模型世界](#模型世界) | 自己的模型成绩和花费、实力榜、角色图鉴、对决和模型测智 | 可选 |

四项可选功能默认开启，可以在 DSH「插件」页的鲸翼详情里单独关闭；关闭后数据保留，重新开启继续使用。

### 专家团队和小鲸助手

- **小鲸当总管**：大多数时候只需要跟小鲸说话。小事它自己做；专业的活找到合适的专家派过去，你批准后专家马上开工，派工卡片上看得到正在做、在等你审批还是做完了，小鲸核对交付后向你汇报。没有合适的专家、又是长期要做的事，小鲸提议新建一位，你同意后由它来建。
- **10 位内置专家**：小鲸助手、产品、设计、研发、测试、运维、数据、研究、写作、运营。每位有一份完整的岗位说明（使命、底线、工作流程、交付模板、自检清单）和默认绑定的专业技能。
- **自己的专家**：10 份模板（售前、实施、财务、法务、翻译、课程、视频编导、招聘、学习教练、效率教练）一键添加，也可以导入模板文件或新建，配置提示词、模型、技能、MCP 和头像。内置专家你改过的部分保留，没改的部分随插件升级；原版有更新时会提示，可以恢复原版。
- **专家记忆**：每位专家一篇记忆笔记，记你定下的规矩和手上的进度，存在知识库里，可以直接改；开工时还会带上《关于我》里你写的“我是谁”“怎样和我协作”。
- **专家团队页**：左边是在用的专家，中间是选中那位的任务对话（可以切换任务、就地开新任务）或专家库，小鲸可以停靠在右侧。能查找、筛选，点名字看专家的概况、记忆和定时任务。
- **小鲸在哪都能用**：平时是右下角一个气泡，点开后悬浮或停靠；重开 DSH 后对话接着上次。小鲸也能帮你管理鲸翼的功能和扩展。
- **随包技能**：每位专家默认带上对口的专业技能，包括鲸翼自写的写作、设计、编码、排查、代码审查、数据分析、调研、视觉物料、汇报演示等，以及收录的 76 项社区开源技能（来自 obra/superpowers、mattpocock/skills、wshobson/agents、phuryn/pm-skills、coreyhaines31/marketingskills、zarazhangrui/frontend-slides、Addy Osmani、Obsidian、ui-ux-pro-max 等）。

### 知识积累

- **第二大脑**：一个存在本机的 Markdown 知识库。首次使用自动建好目录、规则、笔记模板、《关于我》等三篇关于自己的笔记和 Obsidian 视图。
- **阅读和编辑**：左栏找文件和搜索，中间用页签打开笔记，右栏看目录、反链、出链、标签、属性和局部图谱；`Ctrl O` 快速切换到任意一篇。
- **关系图谱**：画出全部笔记之间的联系，可以设置显示哪些、按层上色、样子和排布，还能按建立日期播放“看它长出来”。
- **自动积累**：每日记忆把当天的对话写成日记和任务记录，每周思考写周记和“待你决定”（见[定时任务](#定时任务)）。笔记可以引用到和小鲸的对话里，也带文风检查。
- **团队知识**：装了提供团队知识的扩展（比如鲸翼企业版）时，左下角能切换到团队的知识空间，自己的笔记能提交到团队。

### 技能中心

技能、MCP、插件包三类，各有「我的」和「发现」两面。

- **技能**：「我的」按个人、共用、团队、插件包、内置和各项目分类；可以新建、上传、编辑，改系统技能另存为个人修改、随时恢复原件。「发现」接 skills.sh，预览后安装。
- **MCP**：在鲸翼里填表添加，用 DSH 自带的 MCP 客户端连接，密钥存进 DSH 的凭据库。「发现」里有 22 个核对过的常用 MCP（地图出行、办公协作、文档知识、录音会议、搜索资料、浏览器与图表、开发设计），配置预填好，只需填密钥，每个都写了推荐给哪几位专家用（所有专家和小鲸都能用，不用绑）。
- **插件包**：照 Claude 插件包格式，一个包装一组技能和 MCP，一次装好，一起停用和卸载。随鲸翼带 4 个精选包（录音进第二大脑、出行规划、飞书办公、联网搜索），也可以上传 `.zip` 或添加 GitHub 上的插件包市场。

### 定时任务

- **每日记忆**（每天 01:00）和**每周思考**（每周一 07:00）默认打开；每日阅读开启时还有每天 08:00 的**每日资讯**。
- **自建任务**：填名称、工作指令和时间规则（一次、每隔一段时间、每天、每周或 cron），可以交给某位专家，运行时带上这位专家的岗位说明、技能和记忆。
- 每个任务看得到下次时间、上次结果和执行记录，可以暂停和恢复。运行用你在 DSH 配的模型；关机时不执行，开机后补最近一次。

### AI 网页

- **按事找**：选“写东西、查资料、读长文、做 PPT、画图、做视频、写代码”，只列拿手这件事的 AI 网站。内置 15 个入口（聊天 10 个，画图、视频、搜索、读资料的单项工具 5 个），可以自己添加。
- **提问台**：问题写一次，带上《关于我》和最多 5 篇笔记，发给最多 4 家；内容放进剪贴板后依次打开，窗口够宽时前两家并排。鲸翼不替你在网页里输入或发送。
- **带回来**：在网页里复制要留的回答，点“贴进来”存进知识积累的收件箱，记上问的什么、哪家答的。

### 办公工坊

- 把文件拖进来、粘贴截图，或者把文件夹路径贴进输入框读出来勾选，说要什么结果，交给小鲸：小鲸挑功能项、填好设置，文件在这台电脑上处理，不上传、不覆盖原件。步骤列出来可以点开看，做过的步骤能自己调整后重做。
- 44 项功能项分 7 类：格式转换、PDF 处理、表格处理、图片处理、文字处理、音视频、二维码；知道要用哪一项时，在“全部功能项”里自己点；窗口能收起到页头，切到别的页签照常做完，做好了会提示。
- 做好的事记在“最近做过”里，换个文件就能照原样再做一遍，直接交给功能项，不经过小鲸。
- 在和小鲸的对话里说要处理文件，会转到办公工坊来做，对话里发的附件一起带过来。

### 每日阅读

首页每天一期，一屏看完：左边今日资讯，右边今日一招、接着读、回顾。

- **今日资讯**：每天 08:00 一期，头条一条加快讯几条，每条一行标题配一条一手来源链接；关注的领域和订阅来源可以自己改。阅读设置里开着“按我的情况来挑”时，模型会读知识积累里的《关于我》，把和你有关的排前面；周一多一页上周回顾。
- **存一条**：资讯和技巧都能存进知识积累的收件箱，存的时候写一句为什么存。
- **今日一招**：每天一条能照着做的 AI 使用技巧，可以“让小鲸试一下”（放进小鲸的输入框，自己发），也可以按年月日翻看往期；旁边每天一条鲸翼自己的用法。
- **接着读**：导入 EPUB、TXT、PDF、MOBI、AZW3、DOCX 等格式的书，只存在本机；首页接着读最多两本常看书。读书时选中一句话就能划线，还能写一句自己的话（记进知识积累里这本书的来源笔记，原文不进知识库）。
- **回顾**：划过的线在第 1、7、30 天各回到首页一次。

### 模型世界

- **我的模型**：读 DSH 里配好的模型，对上评测成绩和官网价，按天记用量、估算花费；可以开个对话试用，或确认后设成 DSH 的默认模型。
- **实力榜、新模型**：按综合实力和分项排序筛选，按月看新发布的型号；任意几个模型可以放在一起比。
- **角色图鉴和对决**：19 位原创立绘角色，可以点开看大图、保存（带水印，不能商用）；对决里每位按自己的职业出招，胜负只看综合实力。
- **模型测智**：用社区常用的六道题测自己配的模型，每次现换题面并带口令，提示可能的预制答案和掺水。

### 页头和全部功能

页头只放钉住的常用页签，默认是专家团队、知识积累、技能中心、定时任务、办公工坊，模型世界固定在最右。其余功能在“全部功能”里，按做事、积累、办公、资讯分组，可以钉到页头或取下、调整顺序；按 `Ctrl K`（苹果电脑 `Command K`）用名字或用途搜索后直接打开。打开一个没钉住的功能，页头临时多一个虚线框的页签，可以直接钉住或关掉。窗口变窄时放不下的页签收进“更多”。钉了哪些、怎么排记在这台电脑上。扩展装上后先出现在“全部功能”里，不占页头。

界面跟随 DSH 的浅色、深色主题和你装的皮肤（例如皮肤中心的半透明主题），鲸翼不自己铺底色，只在卡片边缘加一些水纹、回纹之类的小点缀。

## 安装

当前版本 0.2.2-rc.1.3（预发布，还在打磨，适配 DSH `0.2.2-rc.1`）。版本号去掉最后一段就是适配的 DSH 版本，最后一段是鲸翼自己的更新序号：`0.2.1-rc.5.1` 就是适配 DSH `0.2.1-rc.5` 的第 1 版；换 DSH 版本时从 1 重新数，所以最后一段是 1 的版本，都是适配官方最新 DSH 的那一版。

在 DSH 里打开「插件 → 添加插件」，填：

```text
dsh-whalewing@0.2.2-rc.1.3
```

DSH 从 npm 下载安装，不用连 GitHub；官方源连不上会自动换国内镜像，也可以在安装窗口里选“中国大陆镜像源”。安装窗口右侧的「安装源」如果显示的是公司或学校的内网源，DSH 只问这一个源、不会自动换；内网源没有同步鲸翼时会报“无法连接插件源”，把「安装源」改成“中国大陆镜像源”或“npm 官方源”再装。`@` 后面的版本号要带上：只填 `dsh-whalewing` 时，新版本发布满一天才会被选中。

装不上时有两个备用办法，装上的插件完全一样：

- **安装包**：从 [Releases](https://github.com/gwen-liu/whalewing/releases) 下载 `dsh-whalewing-0.2.2-rc.1.3.tgz`，在「添加插件」里填这个文件在本机的绝对路径。
- **GitHub 地址**：填 `github:gwen-liu/whalewing#v0.2.2-rc.1.3`，`#` 后面是版本标签，换成别的标签或提交即可装对应版本；不带 `#` 会装开发主线上的最新代码，不保证稳定。这种方式要先连上 GitHub、再下载整个源码包，DSH 连 GitHub 超过 5 秒就判失败，国内网络下常常装不上。

`0.2.2-rc.1.3` 需要 DSH `0.2.2-rc.1`；用别的 DSH 版本的，到 [Releases](https://github.com/gwen-liu/whalewing/releases) 选版本号以那个 DSH 版本开头的最新一版（`0.2.1-rc.3.2` 之前的版本没有发到 npm，用安装包或 GitHub 地址安装）。DSH 只认插件声明的版本，升级 DSH 后旧版鲸翼不会加载，在「插件」页显示为 `dsh-whalewing`、标着“异常”，旧版的检查更新也用不了。已经装了鲸翼的，在「添加插件」里填新版本的安装包地址（如 `https://registry.npmmirror.com/dsh-whalewing/-/dsh-whalewing-0.2.2-rc.1.3.tgz`）原地换新版，不用卸载，数据和设置都在，重启 DSH 后生效。原版 DSH 即可使用，与定制版的个别体验差异和从旧版升级的方法见[兼容与升级](COMPATIBILITY.md)。

**更新**：`0.2.1-rc.5.4` 起，在 DSH「插件」→ 鲸翼的详情页（或鲸翼页头的“…”）点“检查更新”：已是最新就什么都不改；有新版本会弹出确认，点“更新”原地装好，不用卸载，数据和设置都在，重启 DSH 后生效。DSH 0.2.2 起，按包名装的鲸翼在详情页上方还有 DSH 自己的「版本」区块，它只把正式版当作可更新，鲸翼的版本都算预发布，不会提示鲸翼有新版本，请用鲸翼的“检查更新”。更早的版本可以在「添加插件」里填新版本的安装包地址（如 `https://registry.npmmirror.com/dsh-whalewing/-/dsh-whalewing-0.2.2-rc.1.3.tgz`）原地更新；只填包名会被 DSH 拦下、要求先卸载。

## 扩展

可以给鲸翼开发自己的扩展（依赖鲸翼的独立组合包），不需要改鲸翼源码：从[起步模板](examples/feature-starter/README.md)或[保存状态模板](examples/stateful-feature/README.md)开始，接口和安装、卸载流程见 [EXTENDING.md](EXTENDING.md)。扩展可以加自己的功能页，也可以向专家团队、知识积累、技能中心和定时任务提供专家、知识、技能和任务。

## 数据存放

| 内容 | 位置 |
|---|---|
| 个人知识库 | 插件配置 `vaultRoot`；Windows 默认在 DSH 安装目录同级的 `whalewing-vault` |
| 专家记忆 | 个人知识库里的 `00-系统/专家记忆/`，一位专家一篇，可以直接改、删 |
| 专家配置、定时任务、派工记录、MCP 定义 | DSH 当前 profile 的存储 |
| 技能、插件包 | 用户目录 `~/.dsh/skills`；系统技能和插件包在其中的 `.system/whalewing` |
| MCP 密钥 | DSH 的凭据文件 `~/.dsh/.credentials.yaml`，鲸翼不另存 |
| AI 网页入口、每日资讯 | profile 目录下 `whalewing-ai-web`、`whalewing-news` |
| 书架 | profile 目录下 `whalewing-library`；只存导入或下载的书的阅读副本，不上传 |
| 定时任务执行目录 | DSH 数据目录下 `whalewing-tasks`（侧栏“鲸翼定时任务”） |
| 办公工坊的会话目录 | DSH 数据目录下 `whalewing-toolbox`（侧栏“鲸翼办公工坊”）；处理结果在你点“保存”后才写进你选的文件夹 |
| 模型数据快照 | profile 目录下 `cache/whalewing-model-world`；点「更新数据」才联网获取 |
| 模型用量账本、手动对应、测智记录 | profile 目录下 `whalewing-model-world`；只在本机，不上传 |

停用、升级或替换插件都不会删除这些数据。插件升级时知识库的规则和模板换成新版，你改过的原件另存在知识库的 `.whalewing/replaced/` 下；笔记不动。

联网的只有你主动触发或已启用的动作：模型对话、资讯订阅抓取、模型数据更新、AI 网页、技能市场和插件包市场、MCP 连接、在线书目下载、检查更新。

## 模型世界的数据

模型目录和价格来自 [models.dev](https://models.dev)；综合实力取 Artificial Analysis 智能指数，推理、编程、智能体分项采用 [Epoch AI](https://epoch.ai/benchmarks) 收录的第三方评测，不采信厂商自报。角色立绘由鲸翼作者原创，见[立绘说明](content/model-world/portraits/NOTICE.md)。

综合实力默认使用随插件发布的数据，不需要任何 Key。想随时更新到最新，可以在模型世界点「综合实力数据」，按提示到 Artificial Analysis 免费注册并生成自己的 API Key，粘贴保存后再点「更新数据」。Key 只保存在本机 DSH 的凭据文件里，不进知识库，也不随插件导出。

## 使用限制

办公工坊在浏览器里本地处理：单文件 25 MB、总量 100 MB、PDF 200 页、音视频 30 分钟以内；扫描件 PDF 不做文字识别。小鲸默认只看文件名、大小、页数和表头，你要求时才读内容。Office 转 PDF 用 DSH 自带的转换；PDF 水印只内置常用简繁体字，含生僻字时处理前提示换字。保存用 DSH 自带的另存为（网页版是下载）。
